# LiDF: Layer-wise Intrinsic Dimensionality of FFNs

Official repository for the NeurIPS 2026 paper

**Measuring Layer-wise Intrinsic Dimensionality of FFNs in LLMs via PCA**
Daehee Kim (NAVER Cloud)

> 🚧 **Code release in preparation.** The code will be released here soon.

## What will be released

- **PCA measurement code**: per-layer intrinsic dimensionality $d_\theta$ of the FFN down-projection input, and the dispersion summary $\sigma_{99}$.
- **Width-allocation and KD training scripts**: PCA-guided, uniform and inverted FFN width allocations under a matched parameter budget, with per-teacher recipes.
